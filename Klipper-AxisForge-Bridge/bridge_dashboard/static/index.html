1. Connect the robot

Checking…

Start the PC-side UR driver here. Klipper starts on its own host and only needs the Ethernet connection to this PC.

Complete arm startup manually

  1. Use your existing UR controls to power the arm and release the brakes.
  2. Select Remote Control, start the saved External Control program, and set the speed slider to 100%.
  3. Check the installation, tool TCP and payload in your existing UR setup. The dashboard keeps those settings unchanged.

Power, brakes, mode selection, and program Load/Play are manual actions. Connect robot only launches the configured PC driver and checks feedback.

Zero G-code A/B/C uses AxisForge’s saved orientation in the robot Base frame. It does not mean zero robot joint angles or zero values in the pendant’s TCP fields. Homing can correct a starting tilt of up to 0.5° after surface confirmation, without changing your saved Home waypoint.

    2. Home & probe bed

    Checking…

    Place the flat build surface beneath the nozzle. Confirm the nozzle is clear and unloaded, with room around the toolhead. If needed, the cycle first aligns upright by up to 0.5° around the nozzle tip over at least 3 seconds. Then adjust height with the Z controls below and choose Continue to start the search. A continuous Z search finds the approximate height, then a 3 mm upward backoff releases contact before one slower contact refines it. Set the search and contact speeds below. Mesh travel clears the highest measured surface by 3 mm. Each mesh point uses a 0.1 mm near-contact search that stops on load, followed by 0.01 mm precision passes for the saved height. The arm waits for front-left mesh confirmation before measuring the grid and returns to the corrected starting pose afterward.

    Once both homing contacts establish Home, a mesh failure automatically releases contact upward, lifts clear and returns there. The failed scan does not replace the previous valid mesh. Stop probing cancels all movement; lost feedback, unsafe load or an unconfirmed stop blocks automatic return.

    Bed dimensions and mesh coverage

    G-code X/Y must stay between zero and the bed width/depth, including purge lines and end-of-print parking. The next mesh is centred on the homing position and fits inside the edge margin. Save, re-probe, then repeat job preflight; a mesh for a different bed size is rejected.

    Homing and mesh settings

    Loading…
    Saved settings for the next routine

    Initial search: 0.5–10 mm/s; 5 mm/s is the default, not the minimum. Fine rehoming must be slower. Click Save homing settings to apply changes to the next run.

    Start homing above the bed centre. That nozzle X/Y position becomes the centre of the new mesh. At 0°, bed +X/+Y follow robot Base +X/+Y, so front-left is in negative X and Y. Rotate the bed direction if your viewing position differs; this rotates the grid, not the nozzle. The first point is half the bed width/depth minus the edge margin from centre. The completed mesh carries this same placement into print preflight and execution.

    Maximum Z search is measured downward from the nozzle’s current starting position, which may differ from home. Estimate the current nozzle-to-bed gap and add 50 mm, within the allowed path. Default: 350 mm; adjustable from 5–350 mm. The entire possible search path is checked before motion, even though contact stops descent early. If an earlier attempt already lowered the arm, reduce this range before starting again. Reaching the limit without contact stops the routine; review the travel area before confirming homing.

    Before each live setup move, the bridge checks samples along the full requested path against the UR controller’s active safety limits. A rejected sample or unavailable query blocks movement. This supplements the controller’s safety system; it is not continuous collision checking. Maximum Z search is measured from the adjusted starting pose; the robot’s safety planes can impose a shorter range.

    Slower contacts and repeated measurements improve repeatability; a tighter accepted spread rejects inconsistent readings. Initial homing uses one quick and one fine contact. Choose 1–5 contacts per mesh point; maximum Z spread applies when a point has at least two contacts. One contact cannot measure repeatability. Mesh contact speed is adjustable from 0.02–0.5 mm/s; maximum Z spread from 0.005–0.05 mm. The saved values are shown above. These settings can be saved with the equipment offline. Saving clears job preflight and applies to the next routine.

    Choose 2–9 points along each axis (4–81 points total); the default is 3×3. The grid is centred on the homing start and fits within the saved bed dimensions and edge margin. Upward lifts and retractions default to 10 mm/s; XY travel uses AxisForge’s configured travel speed. Repeated contacts search only near the first measured height, reducing the checks between passes. After measuring the grid, the arm returns to its starting nozzle position. Run this whenever the bed moves. Starting clears saved job preflight.

    Temperature for the next mesh

    Cold probing requires heaters off and the nozzle below 50°C. For heated probing, set matching targets in Fluidd/Mainsail first. The routine waits within ±2°C for the selected soak, then takes a fresh unloaded ALPS baseline. Use a clean nozzle and a surface suitable for the selected temperature. Heater targets remain under Klipper control after completion or Stop.

    A heated nozzle allows a wider unloaded ALPS noise range: 8,000 counts with the default trigger, compared with 5,000 cold. Drift, unloaded-load, contact and overload checks still apply; a short soak may need more time for the sensor to settle.

    Checking the homing service…

    Correct the reported fault and leave the nozzle clear of the surface and unloaded. Review the maximum Z search for the current position. Retry starts fresh checks and asks for surface confirmation again; it does not lift the arm or resume the interrupted movement.

    Move nozzle in Z / lift clear

    After unloaded surface confirmation, use one step at a time to position the nozzle before homing. Every downward positioning step stops on contact. After a recoverable contact failure, the same session offers upward release without resetting the ALPS baseline. XY and orientation stay fixed.

    Start homing and confirm the unloaded surface to enable Z positioning.

    While loaded, use Up 0.1 mm or finer. Larger Up steps become available when fresh readings show the nozzle is unloaded. If load rises during an Up step, that step stops and recovery stays open. Further steps wait for a fresh window below the original release ceiling; no step repeats automatically. Finish recovery ends this attempt; Retry homing starts fresh checks and confirmations. Sensor faults, lost control or an unconfirmed stop require manual recovery.

    3. ALPS load calibration

    Not run

    This routine prepares the scale for supervised ALPS calibration. It does not home the bed or read the weighing scale automatically.

    1. Position the nozzle: use your existing arm controls for XY placement and upright orientation. Confirm the current start pose and an unloaded nozzle above the scale, then use the dashboard Z buttons to leave a gap of at most 20 mm. Choose Continue when ready.
    2. Find and release contact: the routine descends in 0.01 mm steps at 0.1 mm/s, for at most 20 mm. ALPS contact stops the descent; the nozzle then lifts 5 mm at 0.5 mm/s.
    3. Tare and adjust: tare the unloaded scale and confirm. Klipper records the unloaded reference, then use fine Z steps to build the measured load.
    4. Measure and save: apply load with fine Z steps, enter the scale’s actual grams and record. Use Up to unload, then save; Klipper switches heaters off and restarts.
    Calibration conditions

    Manual loading after tare: default 120,000 raw counts, adjustable from 90,000–250,000. Bed homing, mesh probing and the initial scale search use a separate 120,000-count overload limit. These are sensor-signal limits, not rated mechanical forces. Verify the load cell, hotend mount and scale capacities before loading.

    Set the chosen nozzle temperature manually in Klipper’s controls. This page does not turn heaters on. The routine waits within ±2°C of that target for 30 seconds before its baseline. Confirm that the scale/contact surface tolerates the hot nozzle before contact.

    Move nozzle in Z

    Use these controls before the automatic scale search, after tare to apply a measured load, and for upward release after a recoverable contact failure. One click makes one movement; XY and orientation stay fixed. Downward positioning stops on contact; only the load calibration stage permits fine steps to build load.

    Start the scale routine and complete its confirmations to enable Z steps.

    Recovery keeps the original unloaded ALPS reference. Use Up 0.1 mm or finer while loaded; larger Up steps become available after release. Finish recovery ends this attempt without saving calibration. Start a new scale routine afterward. Sensor faults, lost control and unconfirmed stops do not enable dashboard release.

    Fine adjustment and measured load

    Enter the stable load shown by the weighing scale, from 50–25,000 g. This input range is not a mechanical rating. Record sends the measured value to Klipper’s load-cell calibration; it does not move the arm. Do not infer grams from uncalibrated counts. An accepted measurement is used once; stop and restart calibration if that value needs correction.

    Travel is limited to 25 mm above detected contact and 0.25 mm below it. Down steps larger than 0.1 mm must finish at least 0.5 mm above contact; use 0.1 mm or finer to apply load. Use Up to unload before saving. At the calibration load limit, only upward release of 0.1 mm or finer is available while feedback remains valid. Sensor, temperature and motion faults still stop the routine.

    Record a measured load, then use Up until the scale is unloaded. Save turns heaters off and runs Klipper SAVE_CONFIG, which restarts Klipper. It does not move the robot.

    After a verified save, configure ALPS Logger to read Klipper’s saved counts_per_gram and reference_tare_counts. A separate two-weight logger calibration is not required.

    Discards an unfinished Klipper load-cell calibration; saved values are kept. Use if an earlier console session is still open.
